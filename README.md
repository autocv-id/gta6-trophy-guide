# Leonida Trophy Atlas — GTA VI Trophy Guide

The complete Grand Theft Auto VI trophy guide for PlayStation 5: all 55 official trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 PSN-hidden) with a saved checklist tracker, a 9-phase roadmap to the platinum, missable flags with last-chance windows, and a cited guide for every trophy — 147 steps, each one sourced, in our own words. Four disputes where the sources disagree are shown both ways with our call. A spoiler shield hides story trophies until earned. Works fully offline; progress saves in the browser and exports/imports as JSON.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `out/app/index.html` — or serve `app/` with any static server. No build step, no network at runtime.
